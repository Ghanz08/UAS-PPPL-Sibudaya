# QA Workspace

Struktur ini dipisah per QA supaya pekerjaan tidak saling mengganggu.

Aturan singkat:
- QA-1 hanya mengubah folder `qa-1-auth-akses/`.
- QA-2 hanya mengubah folder `qa-2-admin-kelola-lembaga/`.
- QA-3 hanya mengubah folder `qa-3-pengajuan-lembaga/`.
- QA-4 hanya mengubah folder `qa-4-admin-review-config/`.
- Folder `shared/` untuk template dan data bersama.

Catatan automation:
- Kode Selenium JUnit ada di `src/test/java`.
- Resource automation ada di `src/test/resources`.
